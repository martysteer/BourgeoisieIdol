# Making of A Brief Visual Exploration of A Dictionary of Typography

**Source:** https://www.c82.net/blog/?id=86

**Theme:** An historical semantic

## Key Concepts

This project creates a visual timeline of typographic terminology, showing how typeface terms evolved historically. It demonstrates how technical language develops through practice and how visual culture carries semantic history.

## Relevance to BourgeoisieIdol

- Historical semantics and terminology evolution
- Visual representation of conceptual relationships
- Typography as cultural history
- Systematic documentation of design language
