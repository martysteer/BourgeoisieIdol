## Using These Sources

When developing features or making design decisions, consider:
1. How does this reinforce or challenge cultural hierarchies?
2. What alternatives exist to competitive/eliminative models?
3. What gets measured, what gets valued, and who decides?
4. How do technological choices encode political values?
5. What visual language best serves the conceptual framework?

Each source file includes "Relevance to BourgeoisieIdol" section connecting concepts to practical design questions.
