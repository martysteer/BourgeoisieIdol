# International Image Interoperability Framework (IIIF)

**Source:** https://iiif.io/api/index.html

**Theme:** Technology

## Key Concepts

IIIF is a set of open standards for delivering high-quality, standardized digital objects online at scale. It provides APIs for image delivery, presentation, search, and authentication that enable interoperability across repositories and institutions.
