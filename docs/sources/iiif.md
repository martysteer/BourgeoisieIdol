# International Image Interoperability Framework (IIIF)

**Source:** https://iiif.io/

**API Documentation:** https://iiif.io/api/

**Theme:** Open standards, federated infrastructure, interoperability

## Overview

The International Image Interoperability Framework (IIIF) defines several application programming interfaces that provide a **standardized method of describing and delivering images over the web**, as well as "presentation based metadata" about structured sequences of images.

IIIF is a **set of open standards for delivering high-quality, attributed digital objects online at scale**.

## Core APIs

### Image API
Specifies a web service that returns an image in response to a standard HTTP or HTTPS request. The URI can specify the **region, size, rotation, quality characteristics and format** of the requested image.

### Presentation API
Specifies a web service that returns **JSON-LD structured documents** that together describe the structure and layout of a digitized object or other collection of images and related content.

### Search API
Allows for "searching annotation content within a single IIIF resource, such as a Manifest, Range or Collection."

### Authentication API
Describes a set of workflows for guiding the user through an existing access control system.

## Key Benefits

The IIIF aims to **cultivate shared technologies** for both client and server to enable interoperability across repositories, and to foster a market in compatible servers and viewing applications.

If institutions holding artworks, books, newspapers, manuscripts, maps, scrolls, single sheet collections, and archival materials provide IIIF endpoints for their content, **any IIIF-compliant viewer or application can consume and display both the images and their structural and presentation metadata**.

## Community

It's also an **international community** developing and implementing the IIIF APIs.

## Technical Philosophy

- **Open standards** — Publicly documented specifications
- **Interoperability** — Work across different systems
- **Federation** — Distributed rather than centralized
- **Community-driven** — Developed by practitioners, not vendors
- **Vendor-neutral** — No single company controls the standard
- **Attribution** — Metadata travels with images
- **Quality at scale** — High-quality delivery across institutions
