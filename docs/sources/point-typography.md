# Point (Typography)

**Source:** https://en.wikipedia.org/wiki/Point_(typography)

**Theme:** Measurement, precision

## Key Concepts

A point is a unit of measurement in typography, traditionally 1/72 of an inch. The point system provides standardization and precision in typographic design, enabling consistent communication across different contexts.
